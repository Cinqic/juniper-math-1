# Phase 4 Provenance and License Review

> **Historical candidate record.** This review is preserved as provenance
> evidence. For the final approved Phase 4 state, see
> `reports/PHASE4_FINAL_APPROVAL.md`.

## Scope decision: no external sources in v1

`juniper-math-dataset-v1` acquires **zero** third-party data. Every training
and evaluation example is generated by deterministic, seeded Python code
under `src/juniper_math/dataset/generators/`.

### Why

The Phase 4 instructions (Sec. 11) explicitly warn: *"Do not include a
dataset merely because everyone else trains on it,"* and require, for every
third-party source, independently establishing:

- canonical source name, publisher, URL, exact pinned version;
- the actual data license (not just the repository's code license);
- whether that license covers redistribution of the *dataset contents*, not
  merely the surrounding code;
- redistribution and modification rights;
- intended-use compatibility.

Responsibly establishing all of that for a candidate external math corpus
(e.g. verifying that a Hugging Face dataset's stated license actually covers
the underlying problem/answer text, not just a loader script, and that the
license is unambiguous rather than "REQUIRES_REVIEW" in
`manifests/licenses.yaml`'s vocabulary) is a legal-judgment call this
engineering session is not positioned to make responsibly within a single
sitting alongside the rest of Phase 4's scope. Rather than guess — which the
Phase 4 instructions explicitly forbid ("Never guess a license") — the
conservative engineering decision was to exclude external sources from v1
entirely and build a fully self-contained, reproducible corpus instead.

### Consequence: this dataset's provenance is trivially auditable

Because nothing was acquired from a third party, there is no license to
misjudge, no redistribution-rights question to get wrong, and no acquisition
date/URL/version-pin to go stale. The entire corpus's provenance reduces to:
"generated by this repository's own code, at this commit, with this seed" —
independently reproducible by anyone who clones the repository (see
[`docs/DATASET.md`](../docs/DATASET.md) "Rebuilding").

## Manifest entries

- `manifests/sources.yaml`: `phase4-synthetic-dataset-v1` — publisher is the
  project itself, `redistribution_status: NOT_APPLICABLE` (nothing was
  acquired from a third party to redistribute), `transformation_status:
  "generated; not acquired or transformed from any external source"`.
- `manifests/licenses.yaml`: no new entry required. The dataset is licensed
  identically to the rest of the project's source code
  (`juniper-math-1-code`, MIT, already recorded) since it is generated code
  output, not a separate acquired asset. No new runtime or dev dependency
  was introduced by Phase 4 (`python -m juniper_math deps-check` still
  passes with the same dependency set Phase 3 approved).

## Rejected/considered sources

None were formally evaluated to the point of an acquisition attempt. The
scope decision above was made before any specific external dataset was
selected for candidate acquisition, precisely to avoid the failure mode
Sec. 11 describes: "accessible does not mean licensed for training."

## Future external-source integration (out of scope for v1)

If a future dataset version adds external sources, the acquisition path
already has the infrastructure to support it without rearchitecting:
`manifests/sources.yaml`'s schema (`source_id`, `publisher`, `source_url`,
`source_version`, `license_id`, `redistribution_status`,
`transformation_status`, `checksum`) already accommodates a
`REQUIRES_REVIEW`/`NOT_ALLOWED` outcome, and `python -m juniper_math
manifests-validate` already enforces that every entry declares a valid
`redistribution_status`. What is missing is the actual, careful, source-by-
source legal review — deliberately not attempted here.

## Sign-off

This report documents a scope decision, not a completed external-source
audit. GPT-5.6 Terra is authorized to independently propose and evaluate
candidate external sources for a future dataset version, per the Phase 4
instructions' Terra authority list, but no such evaluation is claimed here.
